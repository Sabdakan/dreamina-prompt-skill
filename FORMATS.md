# Formats

Generate at the nearest ratio Dreamina offers, a little larger than needed, then crop to the exact size in an editor. Keep the subject inside the central area: capsules and feeds crop and overlay.

Ratios on the screen (seen 2026-11-20): Seedream 5.5 and 5.0 Pro offer Auto, 1:1, 3:4, 16:9, 4:3, 9:16, 2:3, 3:2 and 21:9; 5.0 Pro also 9:21. There is no 4:5 and no 2:1: generate at the nearest and crop. For a size above 2K, use Seedream 5.0 Pro (up to 4K) or Creative upscale (to 8K) on the kept picture.

## Steam

Sizes from Steamworks' asset pages, read 2026-11-19. Check Steamworks before upload.

| Asset | Size (px) | Generate at | Rules |
|---|---|---|---|
| Header capsule | 920 x 430 | 21:9 or 16:9, crop | Title logo, easily legible; no other text |
| Small capsule | 462 x 174 | from the header art | The logo nearly fills it |
| Main capsule | 1232 x 706 | 16:9 | Key art + logo; no other text |
| Vertical capsule | 748 x 896 | 3:4, crop | Key art + logo; no other text |
| Page background | 1438 x 810 | 16:9 | Quiet; Steam tints it |
| Library capsule | 600 x 900 | 2:3 | Key art + logo; no other text |
| Library header | 920 x 430 | 21:9 or 16:9, crop | As the header capsule |
| Library hero | 3840 x 1240 | 21:9, Creative upscale and crop | No text at all; faces and key content inside the central 860 x 380 safe area |
| Library logo | 1280 wide and/or 720 tall | not generated | Transparent PNG of the logo; made by the user |
| Screenshots | 1920 x 1080 or larger, 16:9 | not generated | Real gameplay only: no concept art, no marketing copy |

- Capsules carry no review quotes, award lines or extra words; the title is placed as the real logo in an editor.
- Generated art used on the store is declared in Steamworks' AI content survey.
- One key art, recomposed per capsule, keeps the page reading as one game: write the widest version first, then crops and re-framings of it as edits or with Expand image (IMAGE.md, "Editing").

## Social

| Destination | Ratio | Size (px) |
|---|---|---|
| TikTok, YouTube Shorts, Instagram Reels, Stories | 9:16 | 1080 x 1920 |
| Instagram feed | 4:5 (generate at 3:4, crop) | 1080 x 1350 |
| X, Bluesky post image | 16:9 | 1600 x 900 |
| YouTube thumbnail | 16:9 | 1280 x 720 |
| Reddit post | 4:3 or 16:9 | 1600 x 1200 / 1600 x 900 |
| Discord server banner | 16:9 | 960 x 540 |

In 9:16, keep text and the focal action out of the bottom fifth and the right edge, where the app's buttons and captions sit.

## In-game pictures

Cards and icons are made square, at least 1024 x 1024, and judged at their in-game size: a 128 px card must read in silhouette. File names follow the project's own list (PROJECT-NOTES.md, or `<id>.png` by default).
